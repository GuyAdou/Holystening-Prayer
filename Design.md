# Holystening — Design Identity

## Color Palette

### Background
| Name | Hex | Usage |
|------|-----|-------|
| Navy Deep | `#1a1a2e` | Gradient start (active session bg, dark text on white) |
| Navy Mid | `#16213e` | Gradient middle |
| Navy Darker | `#0f3460` | Gradient end |
| White | `#ffffff` | Default background (idle / no session) |

### Accent
| Name | Hex | Usage |
|------|-----|-------|
| Mint | `#a8edea` | Primary accent — button gradient, progress bar, loop toggle, Focus On indicator |
| Blush | `#fed6e3` | Secondary accent — button gradient end, progress bar end |

### Buttons
| Name | Hex | Usage |
|------|-----|-------|
| Gray Light | `#e8e8e8` | Play button fill (inactive), gradient start |
| Gray Mid | `#d0d0d0` | Play button fill (inactive), gradient end |

---

## Gradients

**Active session button**
`#a8edea` → `#fed6e3` (top-left to bottom-right)

**Dark background**
`#1a1a2e` → `#16213e` → `#0f3460` (top-left to bottom-right)

**Progress bar**
`#a8edea` → `#fed6e3` (leading to trailing)

---

## Typography

- **App title "Prayer"** — SF Serif, 42pt, weight thin
- **Body / track info** — SF Serif, 17pt, weight regular
- **Captions / labels** — SF, caption size
- All type on dark background: white or `#a8edea` (mint)
- All type on white background: `#1a1a2e` (navy)

---

## Principles

- **Minimal** — one action visible at a time, no visual noise
- **Calm** — soft gradients, no harsh colors, thin weights
- **Sacred** — serif type, generous spacing, nothing competing for attention
