# Holystening — Onboarding Flow

**App Name:** Holystening
**Platform:** iOS

## App Overview
Holystening is a minimalist iOS prayer app. The core value is undistracted prayer — instrumental music plays, the screen dims to ambient mode, and notifications are silenced. Onboarding must deliver the full distraction-free experience before the user's first session. Focus Mode setup is not a secondary feature — it is what separates prayer from just playing music. The UI is intentionally bare: one play button, soft music, a dimming screen. No account, no sign-in, no ads.

## Screen 2 — Silence your phone
*Description: The most important step. The app cannot block notifications on its own — iOS requires the user to set up a Focus Mode automation that activates when Holystening opens. This step must happen before the first session or the value is incomplete. No deep-link button — iOS has no public URL scheme for the Focus section. Show the steps clearly and let the user confirm when done.*

> **Block everything out.**
> Set your phone to silence all notifications when you open this app.
>
> **Settings → Focus** → Select or create a Focus → **Set Schedule → Add Schedule → App → Holystening**

> **Tap the circle** to start and stop. Music fades out gently when you stop.
